# Git practice checklist

- [ ] `git init`, inspect `git status`
- [ ] `git add` and `git commit`
- [ ] Add GitHub SSH remote and `git push -u origin main`
- [ ] Create feature branch, make a change, commit and push
- [ ] Open and merge a GitHub Pull Request
- [ ] Practise `git fetch`, `git log --oneline --graph --all`
- [ ] Practise `git pull --rebase`
- [ ] Create a tag: `git tag -a v1.0.0 -m "NatureHoney 1.0.0"` and `git push origin v1.0.0`
- [ ] Practise reverting a commit with `git revert COMMIT_ID`
- [ ] Verify build output is ignored by `.gitignore` (`target/`)
